# 🏫 Sistema Escolar - Teste Escola

Bem-vindo ao repositório **Teste Escola**!
Este projeto foi desenvolvido com o objetivo de praticar conceitos de programação, versionamento com Git e organização de projetos no GitHub. O sistema representa uma aplicação escolar simples, podendo ser utilizado para estudos, testes e evolução acadêmica.

## 📚 Sobre o Projeto

O **Teste Escola** é um sistema voltado para gerenciamento escolar, permitindo organizar informações acadêmicas de forma simples e prática.

O projeto foi hospedado no GitHub utilizando controle de versão com **Git**, ferramenta amplamente utilizada no desenvolvimento de software moderno. ([GitHub Docs][1])
